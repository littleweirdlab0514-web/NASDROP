# NASDrop 크롬 확장 설치 및 사용 안내

NASDrop 확장은 공유 사이트의 다운로드를 NASDrop 서버로 보내는 도구입니다. 확장만 설치해서는 동작하지 않으며, NAS에서 NASDrop 서버가 실행 중이어야 합니다. 현재는 Chrome 웹 스토어 배포가 아닌 **개발자 모드 설치용 미리보기 버전**입니다. 실제 NAS에서 전체 전송 과정의 검증은 아직 완료되지 않았습니다.

## 1. NAS 준비

1. [NASDrop 프로젝트](https://github.com/littleweirdlab0514-web/NASDROP) 안내에 따라 NAS에 서버를 설치하고 실행합니다.
2. NASDrop 웹 화면에서 사용할 계정과 비밀번호를 확인합니다. DSM 로그인 계정과 다를 수 있습니다.
3. 웹 화면에서 다운로드를 저장할 기본 폴더를 선택하고 쓰기 권한을 확인합니다.
4. 아키라박스·바이킹파일은 서버 **0.9.19 이상**이 필요합니다. 확장 업데이트만으로 NAS 서버가 업데이트되지는 않습니다.

## 2. 확장 ZIP 다운로드 및 압축 해제

0.5.1에서는 파일을 클릭하면 해당 카드 안에 제어 버튼과 비밀번호 입력창이 함께 펼쳐집니다. 다시 클릭하면 접히며, 자동 압축 풀기는 상단에서만 설정합니다.

1. [확장 프로그램 공개 페이지](https://github.com/littleweirdlab0514-web/NASDROP/releases/tag/chrome-v0.5.1)를 엽니다.
2. **Assets**에서 `NASDrop-Chrome-0.5.1.zip`을 받습니다.
3. `Source code (zip)`은 저장소 전체 소스이며, `.spk`는 NAS용 설치 파일입니다. 크롬에는 확장 전용 ZIP을 사용하세요.
4. ZIP 전체를 `C:\Tools\NASDrop-Chrome`처럼 계속 보관할 폴더에 압축 해제합니다.
5. 해제한 폴더에 `manifest.json`, `background.js`, `popup.html`, `icons`, `_locales`가 바로 보이는지 확인합니다. 폴더가 한 겹 더 있다면 그 안쪽 폴더를 선택해야 합니다.

ZIP을 그대로 선택하거나 압축파일 안에서 HTML을 실행하는 방식은 아닙니다. 설치 후에도 해제한 폴더를 이동하거나 삭제하지 마세요.

## 3. 크롬에 설치

1. **PC용 Google Chrome** 주소창에 `chrome://extensions`를 입력하고 Enter를 누릅니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다. Chrome 버전에 따라 버튼 번역은 조금 다를 수 있습니다.
4. 앞에서 해제한 폴더 중 `manifest.json`이 직접 들어 있는 폴더를 선택합니다.
5. **NASDrop for Chrome** 카드가 표시되고, 버전이 **0.5.1**이며 사용 설정이 켜져 있는지 확인합니다.
6. 크롬 오른쪽 위 퍼즐 모양 확장 프로그램 메뉴를 열어 NASDrop의 핀을 누르면 아이콘을 고정할 수 있습니다.

[Chrome 공식 설치 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world?hl=ko#load-unpacked)도 참고할 수 있습니다. 이 안내는 모바일 Chrome용이 아닙니다. 회사·학교에서 개발자 모드를 차단했다면 관리자에게 문의하세요. 정책을 우회하지 마세요.

## 4. NASDrop 연결

1. 툴바의 NASDrop 아이콘을 클릭합니다.
2. 위쪽에서 언어를 선택합니다. **자동**이면 브라우저 언어를 따르고, 알 수 없거나 지원하지 않는 언어는 영어가 기본입니다. 영어·한국어·중국어 간체·일본어를 지원합니다.
3. NASDrop 주소를 입력합니다. 예: `http://192.168.1.10:8791`. 실제 NAS 주소로 바꾸고, 필요한 경우 포트까지 입력하세요. DSM 제어판 주소와 NASDrop 주소는 다를 수 있습니다.
4. NASDrop 웹 화면에서 쓰는 아이디와 비밀번호를 입력한 뒤 **연결**을 누르거나 비밀번호 칸에서 Enter를 누릅니다.
5. 첫 로그인에서 Chrome이 추가 권한을 요청하면 본인의 NAS 주소인지 확인하고 **허용**을 누릅니다. 그다음 툴바의 NASDrop 아이콘을 눌러 확장을 다시 열고 **다시 로그인**하세요. 필요하면 비밀번호도 다시 입력합니다. 권한 허용만으로 로그인이 완료되는 것은 아닙니다. [영어·한국어·일본어·중국어 그림 안내](FIRST_LOGIN.md)를 참고하세요. 인증서 경고나 보안 경고가 나오면 우회하지 말고 서버 HTTPS 설정부터 해결하세요.
6. 표시된 **저장 위치**를 확인합니다. 비어 있다면 NASDrop 웹 화면에서 기본 저장 폴더를 지정하세요.
7. **새로고침** 오른쪽의 **자동 압축 풀기**를 선택합니다. 이 선택은 확장에 저장되고 새로 등록하는 다운로드에만 적용됩니다.

## 5. 다운로드 등록과 작업 관리

1. 설치 전에 열려 있던 공유 사이트 탭은 새로고침합니다.
2. 지원 사이트의 파일 공유 페이지를 열고 실제 다운로드 버튼이 준비될 때까지 기다립니다. CAPTCHA가 나오면 사용자가 사이트의 정상 절차를 진행해야 합니다.
3. 광고가 아닌 **공식 다운로드 버튼**을 누릅니다. Buzzheavier는 **Copy download link**도 지원합니다. 아키라박스·바이킹파일은 공유 주소를 수동 입력하기보다 준비된 공식 버튼으로 보내세요.
4. NASDrop에 추가됐다는 안내를 확인한 뒤 확장 아이콘을 열어 작업 목록을 봅니다. 결과가 불확실하면 중복 클릭하지 말고 목록부터 확인하세요.
5. 각 파일의 진행 표시 바로 아래에 **멈추기·다시 시작·삭제**가 표시됩니다. 파일명이나 진행 영역을 클릭하면 압축 해제 옵션·암호 입력이 열립니다. 서버가 후처리를 시작했거나 완료한 작업은 일부 설정을 변경할 수 없습니다. 완료된 작업에는 **기록 삭제**가 표시되며 NAS의 파일은 유지됩니다.

- **멈추기:** 이어받을 수 있도록 임시 파일을 남깁니다.
- **중지 중:** 실제 작업이 종료될 때까지 다시 시작과 삭제가 잠깁니다.
- **다시 시작:** 멈춘 작업을 재개합니다. 만료된 다운로드 주소는 새 등록이 필요할 수 있습니다.
- **미완료 작업 삭제:** 확인 후 받던 임시 파일과 작업 기록을 지웁니다. 되돌릴 수 없습니다.
- **완료 작업 기록 삭제 / 완료된 작업 삭제:** NAS에 저장된 결과 파일은 유지하고 기록만 지웁니다.
- **암호 필요:** 작업을 눌러 암호를 입력하고 저장합니다. 알림이 보이지 않으면 Chrome·운영체제 알림 설정도 확인하세요.

## 6. 기존 버전 업데이트

1. 새 확장 ZIP을 다운로드하고 임시 폴더에 압축 해제합니다.
2. 기존에 설치한 확장 폴더의 파일을 새 파일로 교체합니다. 기존 폴더 경로는 유지하세요.
3. `chrome://extensions`에서 NASDrop 카드의 **새로고침/Reload** 아이콘을 누릅니다.
4. 확장을 열어 버전과 설정을 확인하고, 공유 사이트 탭도 새로고침합니다.

같은 폴더에서 업데이트하면 저장된 환경설정을 유지할 수 있습니다. 두 번째 복사본을 별도로 설치하지 마세요. 언어·자동 압축 풀기 설정은 NAS 전역 설정과 별개입니다.

## 7. 자주 겪는 문제

| 증상 | 확인할 내용 |
| --- | --- |
| 매니페스트를 찾을 수 없음 | ZIP 압축을 모두 해제했는지, 선택한 폴더 바로 안에 `manifest.json`이 있는지 확인 |
| 아이콘이 없음 | 확장 사용 설정 및 퍼즐 메뉴의 고정 여부 확인 |
| 서버 연결 실패 | 동일한 NASDrop 주소가 일반 탭에서 열리는지, 서버 실행 상태·주소·포트·Chrome 권한 확인 |
| 다운로드 버튼에 반응 없음 | 확장 Reload 후 사이트 새로고침, 사이트 접근 권한과 공식 버튼 여부 확인 |
| 서버 미지원 안내 | NAS 서버 0.9.19 이상인지 확인. 확장만 업데이트한 것은 아닌지 확인 |
| 업데이트 뒤 확장 컨텍스트 오류 | 오래 열린 사이트 탭을 새로고침 |
| 링크 만료 또는 오래된 작업 실패 | 공유 페이지를 새로 열어 새 링크로 새 작업 등록. 먼저 기존 목록을 확인해 중복 방지 |

오류를 문의할 때는 확장·서버 버전과 오류 문구 또는 화면을 보내주세요. 비밀번호, 세션 토큰, 서명이 포함된 직접 다운로드 주소는 공개하지 마세요. 사이트의 IP·접속 제한 때문에 NAS에서 받지 못할 수도 있습니다. 확장은 브라우저 쿠키를 NAS로 복사하지 않습니다.

## 8. 제거

`chrome://extensions`의 NASDrop 카드에서 **삭제**를 누르면 됩니다. 확장 설정은 없어지지만 NAS 서버와 이미 등록된 작업은 그대로입니다. 작업을 중단하거나 삭제하려면 NASDrop에서 별도로 처리하세요. 확장 제거 후에는 압축 해제했던 폴더를 정리할 수 있습니다.
