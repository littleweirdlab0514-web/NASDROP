# NASDrop 0.9.28-3 — Buy Me a Coffee support link

NASDrop now directs voluntary project support to `https://buymeacoffee.com/littleweirdlab0514` instead of GitHub Sponsors.

The NAS settings page uses the new destination in English, Korean, Japanese, and Chinese. GitHub's repository funding configuration uses the same URL as a custom funding link, and README includes it in the support section. External links retain `noopener noreferrer` isolation when opened in a new tab.
