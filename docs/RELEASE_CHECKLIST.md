- [x] 번들 Node.js `linux-x64-glibc-217` 런타임 실행 성공
- [x] 서비스 주소에서 DSM 아이콘 외부 포트를 저장하고 아이콘 재실행 시 적용 확인
- [x] 패키지 시작 후 포털 접속 성공
- [ ] 기본 공유 폴더 쓰기 성공
- [ ] 새 설치 시 기본 저장 폴더가 비어 있고 폴더 선택 전 다운로드가 차단됨
- [ ] 접근 코드 발급 및 웹 포털 로그인 성공
- [ ] GigaFile, GoFile, Pixeldrain 각각 검사·다운로드 확인

- [ ] 패키지 중지·업데이트·제거 동작 확인
- [ ] 영어 기본값과 한국어·일본어·중국어 자동/수동 전환 확인
- [ ] SPK의 INFO·생명주기 스크립트가 LF 줄바꿈인지 확인
- [ ] 모든 생명주기 스크립트와 번들 Node.js에 실행 권한이 있는지 확인
- [ ] SPK 최상위에 NASDrop `LICENSE`가 포함되어 있는지 확인
- [ ] `package.tgz`에 NASDrop `LICENSE`, `THIRD_PARTY_NOTICES.md`, Node.js 및 QR 코드 라이선스가 포함되어 있는지 확인

## 배포 기록

산출물 이름, SHA-256, 빌드 일시와 실기기 테스트 결과를 GitHub 릴리스 노트에 기록합니다. 빌드 성공과 실기기 동작 확인은 별도로 표시합니다. NASDrop은 Synology 공식 패키지 센터에 등록된 앱이 아니므로 릴리스 노트에는 GitHub에서 SPK를 받아 수동 설치하는 비공식 패키지임을 명시합니다.
