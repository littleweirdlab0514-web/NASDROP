## 배포 기록

산출물 이름, SHA-256, 빌드 일시와 실기기 테스트 결과를 GitHub 릴리스 노트에 기록합니다. 빌드 성공과 실기기 동작 확인은 별도로 표시합니다. NASDrop은 Synology 공식 패키지 센터에 등록된 앱이 아니므로 릴리스 노트에는 GitHub에서 SPK를 받아 수동 설치하는 비공식 패키지임을 명시합니다.
